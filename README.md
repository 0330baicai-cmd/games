# 游戏收集箱 · Game Shelf

一个用 GitHub Pages 托管的游戏合集，每个游戏都是**单文件 HTML**，点开就玩，手机横屏也能玩。

## 在线地址

- 游戏列表：`https://<你的用户名>.github.io/<仓库名>/`
- 圆环大乱斗：`https://<你的用户名>.github.io/<仓库名>/arena-smash/`

## 目录结构

```
.
├── index.html          游戏列表页（卡片式）
├── arena-smash/
│   ├── index.html      圆环大乱斗（8MB，模型全部内嵌）
│   └── cover.png       封面图
└── README.md
```

## 加新游戏

1. 新建文件夹 `your-game/`，把打包好的单文件 HTML 放进去并命名为 `index.html`
2. 需要封面就放一张 `cover.png`（16:10 最好看）
3. 打开根目录 `index.html`，复制一段 `<a class="card" ...>` 卡片，改标题、描述和链接
4. 提交推送，等 1 分钟 GitHub Pages 自动更新

## 圆环大乱斗 操作

| 平台 | 操作 |
|---|---|
| 电脑 | `WASD` 移动 · `空格` 跳（二段）· **鼠标左键**轻击 · **右键**重击 · `L` 冲撞 · `U` 旋风 · `I` 大招 |
| 手机 | 横屏 · 左下摇杆移动 · 右下两排按钮（轻/重/冲撞、跳/旋风/大招） |
| 双人 | P1: `WASD` + `J/K/L/U/I` · P2: `方向键` + `Enter` + `,` `.` |

规则：3 条命；击飞值到 100% 起有 10% 概率一击打飞出局，每多 10% 增加 5% 概率；大招靠打人充能。

## 许可

代码可自由使用；游戏内三维模型来自 three.js 官方示例（CC0 / Mixamo 示例资源）。
